# SimEdge Prisjakt feed

Publicerad produktfeed för Prisjakt.

- Publik adress: `https://feed.simedge.se/prisjakt.xml`
- Filen genereras och valideras i det separata privata projektet `SimEdge-Feed`.
- Den här katalogen ska endast innehålla den publika XML-filen och GitHub Pages-konfiguration.
- Shopify-snapshots, autentiseringsuppgifter och feedmotorns källkod får aldrig publiceras här.
